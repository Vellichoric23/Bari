# Ежедневный контент BARI

Приложение читает готовые JSON-файлы из `content/`. Claude кладёт их сюда каждое утро. Если файла нет, приложение просто показывает «BARI ещё готовит».

## Что готовить на каждую дату `D` (сегодня и завтра, если файла ещё нет)

Город, страна, язык и тема дня берутся из `content/plan.json` по ключу `YYYY-MM-DD`.

| Файл | Когда | Формат |
|---|---|---|
| `content/lessons/D.json` | каждый день | как `content/lessons/2026-10-23.json` |
| `content/cityday/D.json` | каждый день | как `content/cityday/2026-10-24.json` |
| `content/city/<citySlug>.json` | если файла для города нет | как `content/city/rim.json` |
| `content/digest/D.json` | только сегодня | `{"date": D, "items": [{"area","title","what","why","talk"}]}`, 6 пунктов |

### lessons
`{topic, topicName, country, city, title, hook, sections:[{h,text}] (3–4 по 60–90 слов), facts:[3], talk, words:[{it,en,ru,hint}] (3), together, quiz:[{q, options:[4], answer: 0–3, why}] (4)}`.
- `topic` и задание берутся из `plan.json` (`brief`). В воскресенье (`logic`) — повторение уроков недели и 2 логические задачи.
- Поле `it` — слово на языке страны из `plan.json` (`lang`), не обязательно итальянском.
- `together` заполняется только для темы «Кухня».

### cityday
`{date, city, fact, word:{it,en,ru,hint}, history:{year,text}}`. `history` — реальное событие именно этого дня и месяца.

### city
`{city, country, items:{<метка>:{text,tip}}, legends:[{title, kind, text (80–120 слов), where, truth}] (4–6)}`.
Метки `items` должны совпадать с метками, которые приложение показывает для города: при создании нового города возьми их из `CITY_ITEMS` / `COUNTRY_ITEMS` в `index.html`.

## Правила для текста
- По-русски, живо, конкретно, без воды. Только проверенные факты: не уверен — не пиши.
- **Никаких клише** (для Рима: Колизей, пицца, монетка в Треви как таковые). Нужно то, что присуще именно этому городу и не лежит на поверхности: местные обычаи, легенды и мифы, притчи, истории улиц, людей и предметов.
- **Еда:** традиционные блюда описывать как есть, даже со свининой или вином. Но любой совет приготовить — только **халяльная** версия: без свинины и алкоголя, с конкретной заменой.
- Для ребёнка 4 лет — простые безопасные действия.
- Сводка новостей: только важное и интересное, без пустословия, чтобы поддержать светскую беседу.

Коммит: `content: D`. Пушить в `main`.
