# Ежедневный контент BARI

Приложение читает готовые JSON-файлы из `content/`. Claude кладёт их сюда каждое утро. У каждого пользователя свой маршрут по странам, поэтому уроки хранятся **по городу и теме**, а не по дате.

## Структура

| Путь | Что это |
|---|---|
| `content/countries.json` | все страны, их языки и города (`slug` — имя папки) |
| `content/plan.json` | основной маршрут BARI (маршрут Айданы): дата → город, тема, задание |
| `content/backlog.json` | очередь городов, для которых ещё нет полного набора уроков |
| `content/lessons/<citySlug>/<topic>.json` | урок; `topic` ∈ `history, art, lang, film, food, books, logic` |
| `content/city/<citySlug>.json` | карточки города, легенды и 7 «фактов дня» |
| `content/history/MM-DD.json` | «В этот день в истории»: `{date:"MM-DD", year, text}` |
| `content/digest/YYYY-MM-DD.json` | утренняя газета BARI Daily: журнал-газета: обложка, цифра дня, 6 журналов по 3–4 истории, колонка BARI |
| `content/ideas/<niche>.json` | идеи по сферам: `smm, teach, biz, beauty, it, creative, student, mom, office, driver, med, build, sales, sport, oil, finance, gov, other` |

## Что делать каждое утро (D0 = сегодня, D1 = завтра, время Атырау)

1. **Газета BARI Daily:** `digest/D0.json`, если его нет (формат ниже, `issues`). Только важное и интересное, без пустословия. Полный выпуск в журнальном тоне (см. формат ниже): обложка, цифра дня, все 6 журналов по 3–4 истории, колонка BARI; погоду — не больше одной заметки на выпуск. Источники: страницы-подборки (10things.news, tengrinews.kz, zakon.kz, inform.kz, lithub.com, lifehacker.ru и т. п.) — одна подборка даёт сразу много новостей.
2. **История:** `history/MM-DD.json` для D0 и D1, если нет.
3. **Основной маршрут:** по `plan.json` для D0 и D1 проверь `lessons/<citySlug>/<topic>.json` и `city/<citySlug>.json`; создай недостающие.
4. **Очередь:** возьми **три первых города** из `backlog.json` (если лимита мало — хотя бы один). Для каждого: Если `city/<slug>.json` ещё нет — создай его. Если он уже есть — не переписывай, только проверь. Затем создай недостающие уроки города (`history, art, lang, film, food, books, logic`) в `lessons/<slug>/`. Когда все 7 уроков на месте — убери город из очереди. Названия `items` в `city/<slug>.json` должны совпадать с CITY_ITEMS (или COUNTRY_ITEMS) в index.html.
   Важно: страна открывается для выбора новым пользователям автоматически, когда хотя бы один её город уходит из очереди (все 7 уроков готовы). Первые города стран стоят в начале `backlog.json` — не меняй этот порядок.
5. **Идеи:** по понедельникам (или если файла нет) обнови все 18 файлов `ideas/<niche>.json` (идеи — практичные советы для этой профессии, без привязки к SMM).

## Форматы

### lessons
`{topic, topicName, country, city, title, hook, sections:[{h,text}] (3–4 по 60–90 слов), facts:[3], talk, words:[{it,en,ru,hint}] (3), together, quiz:[{q, options:[4], answer: 0–3, why}] (4)}`.
- `it` — слово на языке страны (`lang` в `countries.json`).
- `apply` — **польза под профессию**: `{content, teach, biz, team, driver, family}` — по 1–2 предложения, как применить тему урока: content — SMM, блогеры, творчество; teach — учителя и студенты; biz — бизнес, продажи, красота; team — офис, IT, медицина, нефть, госслужба, финансы, стройка, спорт; driver — водители и такси; family — мамы и семья. Конкретно и практично, без воды.
- `together` — только для `food`: как приготовить вместе с ребёнком 4 лет. Иначе пустая строка.
- `logic` — повторение города недели (история, искусство, язык, кино, кухня, книги) и 2 логические задачи.
- Пиши нейтрально, для любого читателя: без имён и без привязки к конкретному человеку.

### city
`{city, country, items:{<метка>:{text,tip}}, legends:[{title, kind, text (80–120 слов), where, truth}] (4–6), days:[{fact, word:{it,en,ru,hint}}] (7)}`.
Метки `items` должны совпадать с метками, которые приложение показывает для города: возьми их из `CITY_ITEMS` / `COUNTRY_ITEMS` в `index.html` (ключ — `mark` города из `countries.json`).

### digest — газета BARI Daily
`{date, edition:"BARI Daily", cover:{kicker, title, lead, mag}, number:{n, text}, column:{title, text}, issues:[{id, items:[{kicker, title, lead, what, why, talk, src, srcName}]}], items:[…]}`.
- `id` журнала: `world` (Мир), `kz` (Казахстан), `money` (Деньги и работа), `books` (Книги: премии, новые книги, экранизации), `stars` (Кино и звёзды: премьеры, люди культуры — без сплетен и слухов), `sci` (Наука и небо). Все 6 журналов, в каждом 3–4 истории (итого 18+).
- `cover` — главная история номера (обложка): рубрика, яркий заголовок, лид в 1–2 предложения, `mag` — id журнала, где она лежит.
- `number` — «Цифра дня»: `n` короткая цифра («$96», «16 регионов»), `text` — одно предложение, почему она интересна.
- `column` — «Колонка BARI»: 2–3 тёплых предложения от BARI про сегодняшний день (без нравоучений).
- `kicker` — рубрика-метка над заголовком одним-двумя словами («Расследование», «Премия», «Небо»).
- `title` — цепляющий журнальный заголовок, не сухой («Мины у Ормуза: нефть подскочила до $96», а не «Цены на нефть выросли»). Цитата в заголовке — отлично.
- `lead` — одна интригующая фраза-подводка курсивом.
- `what` 3–5 предложений с фактами (кто, что, когда, цифры, детали, цитаты), `why` — «Почему это касается тебя»: что это значит для обычного человека в Казахстане, `talk` — одна фраза для разговора, `src` — ссылка на конкретную открытую страницу (не главную).
- **Тон — журнал, а не сводка:** как Esquire/The Village/Forbes Life на русском — живо, с деталью, контекстом и интригой, но без желтизны и кликбейта. Факты только из источника, цифры как в источнике; о политике — нейтрально, без оценок.
- Поиск: до 6 WebSearch и 6 WebFetch на выпуск. Сначала подборки (10things.news «10 things global news <N>th <month>», zakon.kz, bes.media, tengrinews.kz, sciencedaily.com/news/top/science, lifehacker.ru, kinonews.ru, lithub.com).
- `items` — для старых версий приложения: по одной главной новости каждого журнала в старом формате `{area, title, what, why, talk}`.

### ideas
`{week:"YYYY-MM-DD", items:[{t, why, step}] (8–10), dates:[{d:"YYYY-MM-DD", t, idea}] (поводы на ближайшие 2 месяца, только реальные даты)}`.
Идеи — конкретные действия на неделю, `step` — первый шаг на 5–15 минут.

## Правила текста
- По-русски, живо, конкретно, без воды. Только проверенные факты: не уверен — не пиши.
- **Никаких клише** (для Рима: Колизей, пицца, монетка в Треви как таковые). Нужно то, что присуще именно этому городу и не лежит на поверхности: местные обычаи, легенды, мифы, притчи, истории улиц, людей и предметов.
- **Еда:** традиционные блюда описывать как есть, даже со свининой или вином. Любой совет приготовить — только **халяльная** версия: без свинины и алкоголя, с конкретной заменой.
- Для ребёнка 4 лет — простые безопасные действия.
- Новости: только важное и интересное, без пустословия.
- Каждый файл проверь: `python3 -m json.tool файл`.

Коммит: `content: D0`. Пушить в `main`.
